# HFMS

HFMS is a hostel discovery and management interface for students and hostel owners in Kathmandu Valley.

## Replacing photos

The current catalogue uses demo stock images. Replace them with real photos by updating the photo paths in `src/data/hostels.js`; all listing, comparison, detail and homepage imagery is rendered through `src/components/HostelImage.jsx`.
